# 90-Day Progress Tracker

A single-file progress tracker: daily focus blocks, habits, weekly review, products, budget, goals, badges, custom paths, business builder and resource library.

- No build step, no dependencies: open `index.html`.
- Data is saved in your browser (localStorage). Use **Progress > Export JSON / Import** to back up or move devices.

## Host on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root.
